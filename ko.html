틀려도영어 개인정보처리방침

시행일: 2026-08-14 · English

『틀려도영어(Mistakes Welcome)』(이하 "앱")는 계정·회원가입 없이 동작하며, 일기 등 사용자가 작성한 데이터는 사용자 기기 내부에만 저장됩니다. 개발자는 사용자의 개인정보를 수집·보관하는 서버를 운영하지 않습니다.

1. 수집하는 정보

개발자가 직접 수집·저장하는 개인정보는 없습니다. 다만 아래 기능이 동작하는 순간, 해당 데이터가 외부 서비스로 전송되어 처리됩니다.

기능전송 데이터수신자목적
AI 첨삭·힌트·대화일기 텍스트 또는 요약(프라이버시 모드 시 요약만)Google (Firebase AI Logic / Gemini API)첨삭·힌트·대화 생성. 응답 후 앱 표시 목적 외 별도 보관하지 않음
오늘의 사진 검색일기에서 추출한 영어 검색어(풍경 위주)Pexels / Unsplash사진 후보 검색
광고기기 광고 ID 등 광고 SDK 표준 데이터Google AdMob광고 표시 (EEA/영국은 동의 후)

2. 기기에만 저장되는 데이터

일기 원문·첨삭 결과·표현 노트·대화 기록·AI 기억·설정은 모두 기기 내부 저장소에만 저장됩니다. 앱 삭제 시 함께 삭제되며, 백업이 필요하면 앱 내 "데이터 내보내기"를 이용하세요. 안드로이드 자동 백업은 비활성화되어 있습니다.

3. 사용자가 직접 등록하는 API 키(BYOK)

설정에서 본인의 Gemini API 키를 등록하면 키는 기기 보안 저장소에만 저장되며 Google API 호출 외 어디에도 전송되지 않습니다.

4. 데이터 국외 이전

위 표의 수신자(Google, Pexels, Unsplash)는 해외 사업자로, 요청 처리 과정에서 데이터가 국외에서 처리될 수 있습니다. 각 사의 개인정보처리방침이 적용됩니다.

5. 아동의 개인정보

본 앱은 아동을 대상으로 하지 않습니다.

6. 데이터 삭제 방법

모든 데이터는 기기 안에 있으므로 앱 내 삭제 기능 또는 앱 제거로 즉시 삭제됩니다. AI 대화 기억은 설정 > AI 기억 관리에서 개별/전체 삭제할 수 있습니다.
